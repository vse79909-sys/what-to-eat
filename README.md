# 🍳《吃什么》- 小两口专属家庭点菜与排餐系统

专为情侣/家庭量身打造的极简、高颜值、支持拍照录入与周排餐的饮食决策 Web 应用。

---

## ✨ 核心功能亮点

1. **📅 周排餐看板（周一到周日 · 午餐与晚餐区分）**
   - 自动获取真实当前星期与日期（支持查看上周、本周、下周）；
   - 每天清晰分为 **☀️ 午餐** 和 **🌙 晚餐**，点击即可直接从图文菜谱库中点单；
   - 支持一键移除、更新菜品状态。

2. **🍲 精致菜品大厅（图文卡片库）**
   - 预置 10 道家常招牌硬菜与靓汤（可乐鸡翅、番茄炒蛋、排骨汤等）；
   - 支持关键词实时搜索、分类标签快速筛选（家常荤菜、清爽素菜、靓汤、面点等）；
   - 菜品卡片支持一键加入今天午餐/晚餐。

3. **📷 极速拍照录入（做完新菜直接拍）**
   - 手机端直接调起原生摄像头拍照（或从手机相册挑选）；
   - 内置智能客户端图片无损压缩（将实拍照压缩到轻量的高清规格，秒级存储不占内存）；
   - 支持自定义口味标签（如：下饭神器、微辣、大厨拿手）及大厨备忘小贴士（如：“女友爱吃甜，少放葱”）。

4. **⚙️ 站长专属管理后台（自由增删改查）**
   - **完全可自定义**：随时修改菜名、重拍更换照片、修改标签，或删除不合胃口的菜品；
   - **分类管理器**：随心增加或删除自定义分类（如添加“减脂餐”、“周末大餐”）；
   - **数据安全保障**：支持一键导出 `.json` 备份文件，换手机或清理浏览器缓存随时一键恢复。

5. **🎲 “女友选择困难”拯救器**
   - 没主意时，点击“帮我想！一键随机排餐”，算法自动按营养科学搭配一桌菜！

## 🚀 启动与使用方式

### 方式一：电脑一键启动（双击即用）
直接双击根目录下的 **`run.bat`** 即可启动。
程序会自动打开浏览器访问，并在黑框中显示**局域网手机访问网址**。

### 方式二：女朋友手机直接访问
1. 确保女朋友的手机和你的电脑连接在**同一个家里 Wi-Fi**；
2. 在电脑终端启动后，会显示手机访问网址（例如：`http://192.168.1.5:8080`）；
3. 女朋友手机浏览器打开该网址即可直接点菜！
   * **进阶小技巧（变成独立 App）**：在手机 Safari 或 Chrome 浏览器中，点击“分享/菜单” -> **“添加到主屏幕”**，手机桌面就会多出一个带专属图标的《吃什么》App！

### 方式三：无需任何运行环境（直接打开单机版）
直接双击项目中的 **`index.html`**，任何现代浏览器（Edge, Chrome, 360等）均可直接运行。
