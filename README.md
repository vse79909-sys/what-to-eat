## ✨ 核心功能亮点

1. **📅 周排餐看板（周一到周日 · 午餐与晚餐区分）**
   - 自动获取真实当前星期与日期（支持查看上周、本周、下周）；
   - 每天清晰分为 **☀️ 午餐** 和 **🌙 晚餐**，点击即可直接从图文菜谱库中点单；
   - **📋 一键发给大厨**：女朋友选完菜后，点击右上角按钮即可一键复制格式化点菜清单，直接发到微信！

2. **☁️ 小两口跨网络多端实时同步（方案二）**
   - 女朋友在公司用公司 Wi-Fi 或 4G/5G 手机网络，你在家里用电脑或手机；
   - 只要接入免费云数据库（推荐国内版 **MemFire Cloud** 或国际版 **Supabase**），两台手机的数据**毫秒级打通**！
   - 一方上传新菜、一方点明天午餐，对方刷新即可立刻看到。

3. **🍲 精致菜品大厅（图文卡片库）**
   - 预置 10 道家常招牌经典菜品（可乐鸡翅、番茄炒蛋、排骨汤、麻婆豆腐等）；
   - 支持关键词实时搜索、分类标签快速筛选（家常荤菜、清爽素菜、靓汤、面点等）；
   - 菜品卡片支持一键加入今天午餐/晚餐。

4. **📷 极速拍照录入（做完新菜直接拍）**
   - 手机端直接调起原生摄像头拍照（或从手机相册挑选）；
   - 内置智能客户端图片无损压缩（将实拍照压缩到轻量的高清规格，秒级存储不占内存）；
   - 支持自定义口味标签（如：下饭神器、微辣、大厨拿手）及大厨备忘小贴士。

5. **⚙️ 专属管理后台（自由增删改查）**
   - **完全可自定义**：随时修改菜名、重拍更换照片、修改标签，或删除不合胃口的菜品；
   - **分类管理器**：随心增加或删除自定义分类（如添加“减脂餐”、“周末大餐”）；
   - **云端与离线双重保障**：支持云端一键推送与拉取，也支持一键导出离线 JSON 备份文件。

6. **🎲 “女友选择困难”拯救器**
   - 没主意时，点击“帮我想！一键随机排餐”，算法自动按营养搭配一桌菜！

## 🛠️ 如何配置云端实时同步（只需 2 分钟，完全免费）

1. **注册免费数据库**：
   * 推荐中国版 [MemFire Cloud (memfiredb.com)](https://memfiredb.com) —— 中文界面，服务器在杭州/广州，国内 4G/5G 访问极速。
   * 或国际版 [Supabase (supabase.com)](https://supabase.com)。
2. **在数据库控制台运行建表 SQL**（打开控制台的 **SQL 编辑器**，粘贴下方 5 行代码并运行）：
   ```sql
   create table if not exists family_store (
     key text primary key,
     data jsonb not null,
     updated_at timestamp with time zone default now()
   );
   alter table family_store enable row level security;
   create policy "Public Access" on family_store for all using (true) with check (true);
   ```
3. **填入配置**：
   * 打开网页，进入 **「⚙️ 管理后台」** ➔ **「☁️ 小两口跨网络实时同步」**；
   * 粘贴项目的 **Project URL** 与 **anon public key**，点击 **「保存并连接」**；
   * 点击 **「推送本地数据到云端」**，现有的 10 道经典初始菜谱和设置即刻同步到云端！
